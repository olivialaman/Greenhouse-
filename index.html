Microsoft 365 setup

Recommended production deployment.

1. Host the app

Deploy this site to Azure Static Web Apps or SharePoint Framework. Store orders in a SharePoint List or Dataverse table, not browser storage.

2. Sign in

Use Microsoft Entra ID so sales staff and greenhouse staff use their normal Microsoft 365 accounts. Give sales edit access and greenhouse view access.

3. Cancel alerts

Create a Power Automate flow: when an order’s Status changes to Cancelled, post in the greenhouse Teams channel and send the distribution list an email.

Include customer, store number, address, order number, SKU, product, carts, partial-cart pots, due date, Changed By, and notes.

4. Avoid conflicts

Use a single central SharePoint List/Dataverse table. The app filters that list by customer, which removes the need for emailed files or duplicated spreadsheets.
